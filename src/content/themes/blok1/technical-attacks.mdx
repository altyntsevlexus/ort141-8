## Як прочитати адресу сайту

Домен читається **справа наліво** від першої скісної риски.

<CodeBlock label="Приклад" code={`https://google.com.security-check.ru/login
                   └──────┬─────────┘
                    справжній сайт`} />

Отже, це сайт `security-check.ru`, а `google.com` — просто текст, який туди
дописали.

<Callout kind="warn" label="Міф">
  Замок і HTTPS означають лише «з’єднання зашифроване». Фішинговий сайт теж має
  замок. **Замок не означає, що сайт чесний.**
</Callout>

### Справжній чи підроблений

| Адреса | Відповідь |
| --- | --- |
| `privat24.privatbank.ua` | справжній — домен `privatbank.ua` |
| `accounts.google.com` | справжній — домен `google.com` |
| `privatbank.ua.login-secure.com` | підроблений — домен `login-secure.com` |

## Антивірус і брандмауер

Слайда про це в деці немає — але два міфи варто зняти.

**«Треба поставити антивірус».** У Windows він уже є — **Захисник Windows**, і для
домашнього використання цього достатньо.

<Callout kind="warn" label="Міф">
  «Ваш комп’ютер заражено! Завантажте безкоштовний антивірус» — **це і є спосіб
  зараження**. Справжній антивірус не з’являється банером на сайті.
</Callout>

Різниця, яку варто запам’ятати: **антивірус про файли, брандмауер про трафік.**

## Якщо телефонують і просять гроші

Голос більше не доводить, хто на іншому кінці, тому потрібен протокол, а не
кмітливість:

1. **Покласти слухавку.** Це не грубість.
2. **Передзвонити самому** — на номер, який ви знаєте, а не на той, що телефонував.
3. **Кодове слово**, про яке домовились з рідними заздалегідь.

Тиск і поспіх — сама ознака.

## Словник термінів

Виділені **жирним** — для запису в зошит, решта для впізнавання.

| Термін | Англійською | Визначення |
| --- | --- | --- |
| **Атака грубою силою** | brute force | Автоматичний перебір усіх можливих комбінацій символів, доки пароль не збігеться |
| Словникова атака | dictionary attack | Перебір не всіх комбінацій, а готового списку популярних паролів |
| Підстановка облікових даних | credential stuffing | Підстановка пар «пошта+пароль» з витоку одного сайту на інші сайти |
| **Витік даних** | data breach | Потрапляння бази користувачів сайту в руки сторонніх |
| Фальшива точка доступу | evil twin | Wi-Fi-мережа зі знайомою назвою, створена зловмисником |
| **Шкідливе ПЗ** | malware | Загальна назва програм, створених для шкоди чи крадіжки |
| **Вірус** | virus | Чіпляється до файлу чи програми й поширюється разом із нею |
| **Хробак** | worm | Поширюється мережею самостійно, без дій користувача |
| **Троян** | trojan | Замаскований під корисну програму; користувач запускає його сам |
| **Програма-вимагач** | ransomware | Шифрує файли або блокує систему й вимагає викуп |
| Шпигунське ПЗ | spyware | Непомітно збирає паролі, номери карток, історію дій |
| Викрадач паролів | infostealer | Краде паролі, збережені в браузері |
| Рекламне ПЗ | adware | Нав’язує рекламу, підміняє стартову сторінку |
| **Ботнет** | botnet | Мережа заражених чужих пристроїв під централізованим керуванням |
| **DoS / DDoS** | denial of service | Перевантаження сервера запитами, щоб сервіс став недоступним |
| Атака на ланцюг постачання | supply chain attack | Зараження через оновлення легальної програми (Petya) |
| **Дипфейк** | deepfake | Згенеровані ШІ голос або відео реальної людини |
| **Антивірус** | antivirus | Перевіряє **файли й програми** на шкідливий код |
| **Брандмауер** | firewall | Фільтрує **мережеві з’єднання** — який трафік пропустити |
| **Двофакторна автентифікація** | 2FA | Другий крок після пароля: код із застосунку чи SMS |
