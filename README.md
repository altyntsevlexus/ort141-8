# 8-й клас Інформатика ОРТ

Сайт із матеріалами курсу. Публічний, без реєстрації.

**Live:** https://altyntsevlexus.github.io/ort141-8/

## Локальний запуск

```sh
npm install
npm run dev
```

`npm run build` збирає у `dist/`, `npm run check` перевіряє типи.

## Структура

```
src/content/courses/<course>.json      метадані курсу (назва, колір, глиф)
src/content/themes/<course>/<slug>.mdx одна тема
src/components/                        компоненти для конспектів + в’юери
public/pdf/                            файли PDF
```

Кожна тема має один `kind`: `Конспект`, `PDF` або `Презентація`. Kind не входить
в URL — усі три є способами показати одну адресу `/courses/<course>/<theme>/`.

## Як додати тему

Створіть `src/content/themes/<course>/<slug>.mdx`. Обов’язкові поля frontmatter:
`title`, `course`, `kind`, `meta`, `order`.

Для конспекту додайте `outline`, `duration`, `lead` і використовуйте компоненти —
вони доступні без імпорту: `Section`, `Syntax`, `CodeBlock`, `Callout`, `Steps`,
`Practice`, `Keys`, `Screenshot`. Приклади вжитку `CodeBlock` і `Callout`:
[`blok1/technical-attacks.mdx`](src/content/themes/blok1/technical-attacks.mdx).
Решта компонентів поки не використана — вони чекають на перший конспект.

Для PDF додайте `pdf: { file, pages }` і покладіть файл у `public/pdf/`.
Для презентації — масив `slides`. Слайд — це **візуал із заголовком**, а не
сторінка тексту: зміст уроку говорить учитель, слайд лише допомагає. Тому в
слайді є `kicker`, `title`, необов’язковий `visual` і необов’язкова `idea` —
одне речення про те, що означає візуал (схема обмежує його 220 символами).

`visual` буває чотирьох типів:

| Тип | Поля | Коли |
|---|---|---|
| `diagram` | `name` | намальована схема з реєстру (див. нижче) |
| `table` | `head`, `rows`, `reveal?` | коли таблиця і є суттю: порівняння, класифікація |
| `code` | `text` | фрагмент коду або адреси |
| `image` | `src`, `alt` | готове зображення з `public/` |

`reveal: true` ховає всі колонки, крім першої, під сірою плашкою з «?» — питання
класу ставиться до того, як з’являється відповідь. Клік по клітинці відкриває її
й не перегортає слайд.

**Діаграми.** Кожна — окремий компонент у `src/components/diagrams/`,
зареєстрований під іменем у [`diagrams/index.ts`](src/components/diagrams/index.ts).
Невідоме ім’я не ламає деку — візуал просто не малюється. Спільна геометрія
(`VB` 1000×420, шкала `TYPE`, колір небезпеки `WARN`) — у `_shared.ts`; колір
акценту приходить із курсу через `var(--accent)`, тому та сама діаграма в блоку 2
буде іншого кольору. SVG — для схем зі стрілками; там, де треба, щоб текст мірив
себе сам (дужки під частинами адреси, плашки під підписами), діаграма зроблена
на CSS grid.

**Джерела.** Необов’язкове поле `sources` — масив `{ label, note?, href? }`.
Показується під декою: підручник, власна презентація, зовнішнє посилання.

**Додаткові матеріали.** Текст у тілі MDX показується під будь-яким в’юером —
словник, пам’ятка, домашнє завдання.

## Показ презентації

| Клавіша | Дія |
|---|---|
| `→` `PageDown` | наступний слайд |
| `←` `PageUp` | попередній слайд |
| `Пробіл` | наступний слайд (лише на весь екран) |
| `f` | на весь екран |
| `Esc` | вийти |

На весь екран слайд займає весь екран, панель керування ховається за 2,5 с і
повертається від руху мишкою, а клік по слайду перегортає далі. Розмір тексту
пропорційний ширині слайда, тому один набір значень працює і на телефоні, і на
проєкторі.
